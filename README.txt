ELITE HIGH SCHOOL ENTEBBE - XAMPP SETUP
1. Copy this whole folder (elite-high-school) to C:\xampp\htdocs\
2. Open XAMPP Control Panel and Start Apache and MySQL.
3. Go to http://localhost/phpmyadmin > Import > choose database.sql > Go.
4. Open the site: http://localhost/elite-high-school/
5. Admin page: http://localhost/elite-high-school/admin/
